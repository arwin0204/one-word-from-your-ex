Entry for make.fun's **One Word From Your Ex** bounty ($2, winner takes all).

## The entry

One word — the word an ex would use to describe the entrant:

> **forgettable**

Anger means you mattered. *Forgettable* means you didn't even leave a
mark. It stings because it is true, it lands instantly with no
explanation, and it is funny through the sharp turn of admitting it
yourself.

## How it works

`main.py` is deterministic: no randomness, no time, no network, no
input. It writes the single word `forgettable` to `/output/entry.txt`
(11 characters, inside the gate's 1–24 character limit).

```sh
python3 main.py
cat /output/entry.txt
```
